# 🌦️ Weather App (SkyCast)

A modern and responsive **Weather Application** built using **HTML, CSS, and JavaScript**, powered by real-time weather data from an external API.  
This project demonstrates practical usage of the **Fetch API**, `.then()` promises, and dynamic DOM manipulation to display live weather conditions.

🔗 **Live Demo:** https://ahmed-devx.github.io/Weather-App/  
📂 **GitHub Repo:** https://github.com/Ahmed-Devx/Weather-App  

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature & weather conditions
- 💨 Wind speed & humidity details
- 🌅 Sunrise & sunset timings
- 📊 Air quality and atmospheric data
- ⏱️ Hourly weather forecast
- 📅 7-day weather forecast
- 📱 Fully responsive (mobile & desktop friendly)

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure  
- **CSS3** – Modern UI & responsive design  
- **JavaScript (ES6)** – Core logic & API handling  
- **Fetch API** – Real-time weather data fetching  
- **Promises (.then())** – Asynchronous operations  

---

## 📡 How It Works

1. User enters a city name  
2. App sends a request using `fetch()` to the weather API  
3. Data is received in JSON format  
4. `.then()` handles the response and updates the UI dynamically  
5. Real-time weather data is displayed instantly
